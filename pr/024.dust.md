# 算法除尘（手动 + ROI）

## 定位与范围

手动、按需的功能，**不做全自动**——全自动会把星空、雪花、高光等"小而亮且中性的内容"当灰尘抹掉。

本期范围：
- 方形 ROI 选区（多个，拖拽绘制，可删除），ROI 按片名持久化。
- 全局去灰尘力度滑块（粗细程度），对所有 ROI 生效。
- 只做灰尘；划痕本期跳过。

未来扩展（本期只留扩展位，不实现）：
- 粗细滑块下放到**每个 ROI**（`regions[].strength` 覆盖全局）。
- 笔刷工具做任意形状选区，单独调整每次下笔的去灰尘力度。
- 划痕修复并入同一入口。

## 已知局限

1. 无法区分灰尘与星星/雪花/高光（ROI 内也不保证）——由"手动 + ROI + 用户自选"管理误删。
2. 颗粒过大（高感强推、聚团接近灰尘尺度）时判别可能失效——由"粗细程度"滑块兜底。
3. 划痕（细长类）本期不做，未来在同一入口补。

## 物理特征

| | 亮度反差 | 尺寸 | 色度 |
|---|---|---|---|
| 灰尘 | 透底，反差近 100% | 3–15px 实心 | 中性（a≈b≈128） |
| 银盐颗粒 | 密度调制 10–30%（高感聚团更大） | 1–3px（高感 3–5px） | 带色度噪声 |

- 灰尘在负片是全通道近黑的局部暗点，反转后成中性亮斑。
- 色罩是平滑低频信号，在灰尘尺度上近似常数，对检测无影响。
- 灰尘与颗粒的反差差距量化可分：检测阈值设为"颗粒噪声底的 N 倍"即可跨感光度自适应。

## 算法（逐 ROI）

检测（常量已按 `tests/test_dust.py` 原型标定）：
1. ROI 裁剪（向外 pad 一个 inpaint radius，修补后裁掉，保证 ROI 边缘灰尘有插值上下文）。
2. 转 Lab，取 L。
3. 颗粒幅度：`grain = 1.4826 × median(|hp|)`（hp 为 L 高通，MAD 稳健尺度）。灰尘是稀有像素，中位数不受其污染。
4. 白顶帽：`tophat = L − medianBlur(L, dust_size)`，只保留亚灰尘尺度的亮斑。**原型验证**：原设计的 opening 底在纹理区取局部最小值，会把颗粒顶帽放大到与灰尘重叠（粗颗粒下颗粒顶帽 102 vs 灰尘 141）；中值底对亮斑稳健，颗粒大部分抵消、灰尘保持全反差（63 vs 98）。
5. 两段处理（粗细滑块控制）：
   - **灰尘蒙版**：`tophat ≥ t_dust` 且通过连通域/中性验证的斑块 → inpaint 彻底抠除。`t_dust = max(grain × dust_gain, 8)`，`dust_gain = 2.5 + 2.0 × g`（滑块 g=0 细 → 2.5，g=1 粗 → 4.5）。
   - **颗粒衰减**：其余 tophat 响应 `L' = L − α·max(tophat − t_grain, 0)`，`t_grain = 0.7 × grain`。`α = max(0, 1 − g/0.5)`：细端 α→1 抹平颗粒（合成验证颗粒 std 降约 9%），粗端（g≥0.5）α=0 颗粒 1:1 保留。
   - 滑块 细→粗：dust_gain 单调抬高、α 单调减小；粗到极限只抠反差最大的灰尘、漏掉小灰尘（合成验证：粗颗粒下 coarse 档只抓大灰、fine 档全抓）。
6. 连通域过滤：面积 ∈ [4, dust_size²]、圆形度（细长 → 划痕，跳过）。
7. a/b 中性验证：斑块内 |a−128|、|b−128| 均值小（>28 拒绝），且 a/b 标准差远小于 L 标准差。灰尘是中性体、银盐聚团带色度噪声、彩色高光偏色——这一层按色度把"灰尘"和"彩色小内容"分开（合成验证：粉色高光与亚像素星点均存活）。

修补：
- 蒙版膨胀 1–2px 盖半影，L/a/b 三平面分别 `cv2.inpaint(INPAINT_TELEA)`，radius ≈ dust_size/2。
- 只回写蒙版下像素到原图，其余保持 float 精度（管线 0–1 float / 16bit 源）。
- inpaint 用周围颗粒纹理插值修补，比中值滤波保真。

## 管线位置

`process_film_bytestream_with_params` 中：反转 `img = 1.0 - img` 之后、`get_white_point_manual` 之前。

- 先除尘再采样白点：灰尘落在 WP ROI 会把白平衡/色阶顶偏，先除后采样下游更准。
- 必须放在 tone mapping / auto-levels 之前：拉伸会放大残余灰尘，且把灰尘推到 255 裁切导致中性验证失效。

## 配置

本期：

```json
{
  "dust": {
    "enabled": true,
    "grain_level": 0.5,
    "dust_size": 9,
    "regions": [
      { "shape": "rect", "x1": 100, "y1": 50, "x2": 400, "y2": 300, "strength": null }
    ]
  }
}
```

- `grain_level` 0~1（0=细/抹颗粒，1=粗/只抠灰尘），全局，默认取偏粗端（默认不抹颗粒）。
- `regions` 用 basis 坐标系，复用现有 `--area-basis` 的映射（`resolve_wp_roi_to_actual`）。
- `strength: null` 表示跟随全局 `grain_level`——逐 ROI 力度的扩展位。

未来扩展位：
- `regions[].strength` 覆盖全局 → 逐 ROI 力度。
- `regions[].shape: "brush"` + `path` → 笔刷选区。
- 笔刷路径若超出字符串协议承载能力，改走临时 JSON 文件传参。

## CLI

```
--dust "grain_level,dust_size"          # 存在即启用，如 "0.5,9"
--dust-rois "x1,y1,x2,y2;x1,y1,x2,y2"   # 分号分隔多 ROI，逗号分隔坐标
```
